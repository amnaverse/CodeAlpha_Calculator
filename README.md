# 🧮 Calculator App

A basic calculator built with Vanilla JavaScript, using DOM manipulation and input validation. Created during my CodeAlpha frontend internship.

**🔗 Live Demo:** https://amnaverse.github.io/CodeAlpha_Calculator/

## Features
- ➕ Addition, subtraction, multiplication, and division
- 🔢 Decimal number support
- ⌫ Backspace and clear (C) buttons
- ✅ Input validation
- 🖱️ Interactive button layout

## Tech Stack
HTML5, CSS3, JavaScript (Vanilla)

## How to Run Locally
```bash
git clone https://github.com/amnaverse/CodeAlpha_Calculator.git
cd CodeAlpha_Calculator
```
Then open `index.html` in your browser.
